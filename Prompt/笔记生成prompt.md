本文用于约束 AI 辅助生成或整理笔记时的格式与资源管理方式。

# 标题层级

- 不要在正文中重复书写笔记标题。
- 笔记文件名即为标题，正文直接从实际内容的一级标题开始。
- 标题层级应连续递进，不要跳级。

# 排版规范

以下内容的上下均应保留一个空行：

- 标题
- 段落
- 图片
- 公式
- 代码块
- 引用块

一次换行即视为一个新段落。不要使用多余的连续空行。

# 引用块

不要使用 Obsidian Callout 语法。应删除 `[!IMPORTANT]`、`[!NOTE]`、`[!WARNING]` 等标记，仅保留普通 Markdown 引用。

修改前：

```markdown
> [!IMPORTANT]
> 这是需要备注的内容。
```

修改后：

```markdown
> 这是需要备注的内容。
```

# 图片管理

## 存放位置

若文章包含图片，应在 `Assets` 目录下为该文章新建独立文件夹，并将文章使用的所有图片集中存放在其中。

## 命名规则

- 文件夹名和图片文件名一律使用英文。
- 使用简短、明确且稳定的名称，不追求逐字完整翻译。
- 建议统一使用小写字母与连字符，例如 `motion-control-paper`、`rma.png`。
- 图片名应体现图片内容，避免使用 `image-1.png`、`screenshot.png` 等无意义名称。

例如，一篇“运控论文学习”笔记包含 RMA 和 HIM 两张图时，可以使用以下结构：

```text
Assets/
└── motion-control-paper/
    ├── rma.png
    └── him.png
```

## 引用格式

统一使用标准 Markdown 图片语法，不使用 Obsidian 的 `![[...]]` 语法，以确保笔记在其他 Markdown 软件中也能正常渲染。

```markdown
![RMA 架构](相对于当前笔记的图片路径/rma.png)
```

图片路径应使用相对于当前笔记文件的相对路径；替代文本应简洁描述图片内容。

# 完成前检查

- 正文中没有重复出现笔记标题。
- 标题层级连续且合理。
- 各标题、段落、图片、公式、代码块和引用块之间留有一个空行。
- 文中不存在 Obsidian Callout 标记。
- 图片已集中存放在对应的 `Assets` 子目录中。
- 图片目录与文件名均为英文且含义明确。
- 图片使用标准 Markdown 语法和正确的相对路径。
